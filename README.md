# oxygen-binding-proteins

### Scripts for data analysis and figure creation of oxygen-binding proteins paper
- Analyzed data files and scripts used for figure plotting are in separate directories
- Scripts detail which figures are produced and the required data file needed to run
- Raw data and image files are available upon request
